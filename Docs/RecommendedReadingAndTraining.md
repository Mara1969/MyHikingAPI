
# Recommended Reading

## Books

- [The Pragmatic Programmer](https://pragprog.com/titles/tpp20/the-pragmatic-programmer-20th-anniversary-edition/)  
  Introduces practical habits and philosophies that help engineers write better code, communicate effectively, and approach problems with a thoughtful, solution-oriented mindset. Covers essentials like version control, automation, debugging, and soft skills such as ownership and continuous learning.

- [Practices of an Agile Developer](https://pragprog.com/titles/pad/practices-of-an-agile-developer/)  
  Focuses on real-world practices that align with agile principles—writing clean, testable code, collaborating effectively, and responding well to change. Breaks down complex ideas into simple, actionable advice for building confidence and professionalism.

- [97 Things Every Programmer Should Know](https://github.com/97-things/97-things-every-programmer-should-know/blob/master/en/SUMMARY.md)  
  A collection of short, insightful essays from experienced engineers. Each entry offers practical advice or a lesson learned, covering topics from clean code to debugging and teamwork. Great for picking up quick, valuable insights.

- [Clean Code](https://www.amazon.co.uk/Clean-Code-Handbook-Software-Craftsmanship/dp/0132350882)  
  Emphasizes writing code for humans first—clarity, simplicity, and thoughtful design. Shows how to spot and refactor bad code, providing a foundation in coding craftsmanship and habits for higher-quality software and better collaboration.

- [To Sell is Human](https://www.danpink.com/books/to-sell-is-human/)  
  About communication, persuasion, and getting your ideas across—essential skills in software development. Makes soft skills approachable and shows that great communication is about being clear, human, and effective.
